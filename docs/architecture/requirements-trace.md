# Матрица требований FTTC PROF DEV HUB

Основание — исходный PDF ИТМО «Платформа „FTTC PROF DEV HUB“», 13 страниц, SHA-256 `57c939a51762dc0f85023fd232c030015826300b40bb42303411caf8213653bf`. Номера страниц ниже соответствуют PDF. Номера разделов в графе «Решение» относятся к [исходной архитектуре](../FTTC_PROF_DEV_HUB_Architecture_and_Roadmap.md) на `main` в версии `b8cb42f812b695292afb2558bca26c2a2c162043`. Короткие фрагменты в кавычках взяты из PDF. Вопросы в конце документа сохраняют исходное разночтение до решения ИТМО.

В этой версии репозитория есть проектный документ, командные инструкции, шаблоны GitHub и CI для оформления PR. Прикладных компонентов, схем БД, тестовых наборов, отдельного принятого ADR или протокола приёмки заказчика в дереве нет. Закрытые Issues #4, #6 и #8 относятся к процессу разработки. Матрица описывает ожидаемые результаты. Примеры проверок и ограничения пилота — предложения архитектуры, прохождение проверок устанавливается при реализации.

Полный объём определяется PDF. Поставки P0 (MVP), P1 (каталоги и коллаборация), P2 (расширенные встречи и аналитика), P3 (защищённые медиа и распознавание) и P4 (эксплуатационная приёмка) задают последовательность из дорожной карты. Если указаны два этапа, ограниченный пилотный сценарий и полная проверка описаны отдельно. Роль «коллега» обозначает участника проекта, который может совмещать эту роль с ролью преподавателя. Само участие в проекте не даёт доступ к чужому ИПР. Вход через IdP, использование PostgreSQL, выбор языка и календарного сервиса в PDF не предписаны.
