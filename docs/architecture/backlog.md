# Реестр поставок и трассировка в GitHub Issues

Объём и приёмка каждого результата задаются в его Issue. Эпики группируют работу. Зависимости обозначены отдельно от принадлежности к эпику. Утверждение архитектурного PR и протокол ИТМО — разные условия. Три стартовых задачи можно выполнить по действующей main на синтетических образцах, без реализации приложения. Для остальных инженерных задач, использующих новые решения, требуется принятие соответствующего PR. У решений есть ответственные роли и проверяемый протокол.

[Матрица требований и разночтений](requirements-trace.md) · [Порядок работ и расчёт срока](delivery.md).
