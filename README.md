# FTTC PROF DEV HUB

Платформа профессионального развития преподавателей иностранных языков ИТМО. Преподаватель составляет индивидуальный план развития (ИПР), подбирает внутренние и внешние возможности, пополняет портфолио подтверждёнными достижениями и обсуждает следующий план на встрече 1-1 с руководителем.

В репозитории сейчас есть проектная документация и правила совместной разработки. Границы MVP, этапы поставки и открытые решения заказчика собраны в [архитектуре и дорожной карте](docs/FTTC_PROF_DEV_HUB_Architecture_and_Roadmap.md).

[Архитектурная приёмка](docs/architecture/acceptance.md) · [Требования ИТМО и расхождения](docs/architecture/requirements-trace.md) · [План команды](docs/architecture/delivery.md) · [Backlog по требованиям](docs/architecture/backlog.md).

## Как начать работу над задачей

1. Выбери задачу в [GitHub Issues](https://github.com/Dtsyp/FTTC-PROF-DEV-HUB/issues). Порядок работы с задачами, ветками и PR описан в [CONTRIBUTING.md](CONTRIBUTING.md).
2. Открой корень рабочей копии в привычном редакторе или AI-инструменте. Командные [правила работы агента](AGENTS.md) уже в репозитории. Модель, skills и способ делегирования каждый выбирает сам.
3. Можно начать с одной фразы, подставив номер своей задачи:

   > Прочитай AGENTS.md в корне и возьми задачу #42.

   Если агенту недоступна Issue, вставь её текст. Для обычного поручения достаточно описать проблему своими словами.

Для новой рабочей копии команды одинаковы в PowerShell, WSL, macOS и Linux:

```shell
git clone https://github.com/Dtsyp/FTTC-PROF-DEV-HUB.git
cd FTTC-PROF-DEV-HUB
```
